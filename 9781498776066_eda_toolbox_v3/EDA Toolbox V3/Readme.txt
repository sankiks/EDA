with MATLAB Third Edition, W. Martinez, A. Martinez, & J. Solka, CRC Press, 2017.

INSTALLATION 
1. Copy the toolbox folder into a directory of your choice. 
2. Start Matlab and select 'Set path...' using the toolbar button on the ribbon. 
3. Click the 'Add with subfolders...' button,  and 
select the folder for the EDA Toolbox in the file dialog, and press Open. 
4. Subsequently, press the Save button in order to save your changes to the 
Matlab search path. The toolbox is now installed.

Known Bugs (June 2017):
MATLAB changed its graphics engine with later releases of MATLAB. We are in the process of
updating the functions. The main affected functions are those that implement the data
tours, scatterplot brushing, and some of the GUIs.
